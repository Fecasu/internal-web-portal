# Internal Web Portal

## PL Opis

**Internal Web Portal** to prosty projekt frontendowy przedstawiający wewnętrzny portal firmowy.

Aplikacja zawiera dashboard, listę dokumentów z wyszukiwarką, sekcję aktualności oraz formularz kontaktowy z podstawową walidacją. Projekt został przygotowany w celu przećwiczenia podstaw Reacta, JavaScriptu, HTML/JSX oraz CSS, ze szczególnym naciskiem na tworzenie responsywnych interfejsów podobnych do wewnętrznych serwisów firmowych.

## ENG Description

**Internal Web Portal** is a simple frontend project representing an internal company portal.

The application includes a dashboard, a document list with search functionality, a company news section and a contact form with basic validation. The project was created to practice the basics of React, JavaScript, HTML/JSX and CSS, with a focus on building responsive interfaces similar to internal business web services.

## Features

- Dashboard with summary cards
- Internal document list
- Document search functionality
- Company news section
- Contact form with basic validation
- Responsive layout for desktop and mobile
- Custom CSS styling
